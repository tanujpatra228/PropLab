# Reference Data

## UIUC Propeller Database

**What:** wind-tunnel measurements of small propellers by the University of Illinois Urbana-Champaign Applied Aerodynamics Group (Brandt & Selig). The gold standard for small-prop performance data.

**Source:** [UIUC Propeller Database, Volume 1](https://m-selig.ae.illinois.edu/props/volume-1/propDB-volume-1.html). Reference: J.B. Brandt and M.S. Selig, "Propeller Performance Data at Low Reynolds Numbers", AIAA 2011-1255.

**In PropLab:** `src/data/uiuc-static.js` (used by the app for measured blades and by validation).

| Prop | Static file | Geometry file |
| --- | --- | --- |
| APC 9×4.7 Slow Flyer | `apcsf_9x4.7_static_kt1032.txt` | `apcsf_9x4.7_geom.txt` |
| APC 10×4.7 Slow Flyer | `apcsf_10x4.7_static_kt0835.txt` | `apcsf_10x4.7_geom.txt` |
| APC 11×4.7 Slow Flyer | `apcsf_11x4.7_static_pg0526.txt` | `apcsf_11x4.7_geom.txt` |
| APC 9×4.5 Thin Electric | `apce_9x4.5_static_rd0995.txt` | `apce_9x4.5_geom.txt` |
| APC 10×5 Thin Electric | `apce_10x5_static_pg0819.txt` | `apce_10x5_geom.txt` |
| APC 11×5.5 Thin Electric | `apce_11x5.5_static_kt0467.txt` | `apce_11x5.5_geom.txt` |

All files live under `https://m-selig.ae.illinois.edu/props/volume-1/data/`. Static files were subsampled to 6 evenly spread RPM points each.

### File formats

- **Static:** `RPM  CT  CP` per line.
- **Geometry:** `r/R  c/R  beta` per line: radial station as a fraction of tip radius, chord as a fraction of tip radius, and blade angle in degrees, at 18 stations from 0.15 to 1.00.

### Retrieving more files

The database page lists links to the data files, but some fetch tools strip them. Open the page in a browser and list the links from the console:

```js
[...document.querySelectorAll('a')].map(a => a.href).filter(h => /_static_|_geom/.test(h))
```

Volumes 2 to 4 contain more props, including some multirotor props.

## APC published performance files

**What:** performance tables APC Propellers publishes for every prop, generated by APC's own computational model (not wind-tunnel tests).

**Source:** `https://www.apcprop.com/files/PER3_<model>.dat`, e.g. `PER3_10x47SF.dat`. Static rows are the `V = 0` line of each RPM block.

**In PropLab:** `tests/validation/apc-static.js` (validation only, shown as a secondary reference).

| Model | Line | Notes |
| --- | --- | --- |
| 5x4.5E | Thin Electric | Small prop, not in UIUC volume 1 |
| 8x3.8SF, 10x4.7SF, 11x4.7SF | Slow Flyer | Overlap with UIUC for cross-checking |
| 15x5.5MR | Multi-Rotor | Drone prop, narrower blades |

**Caution:** for the 10×4.7 SF, APC's file reads ~5% higher thrust than UIUC measured. Treat APC data as a sanity check, not ground truth.

APC also publishes maximum RPM rules (Slow Flyer: 65,000 ÷ diameter in inches; Thin Electric: 145,000 ÷ diameter). PropLab uses these to sanity-check its strength model. See [Decisions](decisions.md#d-006-root-thickness-for-the-strength-check).

## Airfoil coordinates

**Source:** [UIUC Airfoil Coordinates Database](https://m-selig.ae.illinois.edu/ads/coord_database.html), as bundled with AeroSandbox. **In PropLab:** `src/physics/airfoil-data.js` (Clark Y, Eppler E63). NACA 4-digit shapes are generated from their standard equations.

## Coefficient definitions

PropLab and both datasets use the same propeller coefficients:

```latex
C_T = \frac{T}{\rho n^2 D^4} \qquad C_P = \frac{P}{\rho n^3 D^5}
```

T thrust (N), P shaft power (W), ρ air density (1.225 kg/m³), n revolutions per second, D diameter (m).

## Adding a prop to validation

1. Get its `_static_` and `_geom` files (UIUC) or `PER3_` file (APC).
2. Add an entry to `src/data/uiuc-static.js` (or `tests/validation/apc-static.js`) following the existing shape.
3. Make sure its product line has an airfoil in `LINE_AIRFOIL` in `scripts/validate.js`.
4. Run `npm run validate`, then update [Validation](validation.md).
